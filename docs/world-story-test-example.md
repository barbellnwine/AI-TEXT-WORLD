# 오프라인 엔진 테스트에서 생성한 예시

운영 세계의 사건이 아닙니다. 테스트가 열쇠를 가진 도영동과 김기업을 생성하고, 제안 → 독립적인 거절 → 숲 탐색을 엔진에 실행시킨 결과입니다. 발견·싸움·사망을 추가하지 않았습니다.

## 짧은 LIVE의 근거

혼자 들고 있기보다 필요한 사람에게 건네고 싶었다. 도영동이 말을 건넸다.

“열쇠를 줄 테니 받아 줄래?”

지금은 열쇠를 사용할 계획이 없었다. 김기업은 제안을 거절했다.

“지금은 필요 없어.”
