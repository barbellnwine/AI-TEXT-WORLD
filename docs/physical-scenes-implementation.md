# 물리적 행동과 DAY 장면 개편 — 2026-09-25

## 실제 원인과 변경

기존 ATTACK 검증은 물건을 사용하는 공격을 `weapon_effect_not_defined`로 거절했다. 공격 완료 단계에는 피해 합계만 있었고, 도구 출처·겨냥한 곳·방어 과정·실제 부상 부위가 없었다. NARRATOR가 구체적인 장면을 쓸 근거가 부족했다.

이제 엔진이 준비와 결과를 `WorldEvent.detail`에 기록한다. AI가 제안한 공격 이유·도구·목표를 검증하고, 상대의 선택 또는 상대 상태와 성향에 따른 즉각 반응을 판정한다. 서술은 그 뒤에 수행한다.

## 새 기록

- 시작·완료 세계 분, 공개 행동 이유, 시각과 행위자별 과정 `steps`.
- 도구 ID·이름·출처(소지/현장/맨손), 원래 물건 ID, 사용 뒤 소유자.
- 접촉 공격 방식, 겨냥한 부위, 상대의 회피/막기/반격 준비/버티기/수면 중 무대응, 반응의 근거.
- 명중/회피/완전 방어/실패, 실제 부상 부위·피해 정도, 재현 가능한 난수와 명중 확률.
- 실제 목격자, 다음 판단을 깨운 이유. 목격 의도를 실제 개입이나 대사로 처리하지 않는다.
- 자원 사용 위치·수량, 실제 발언의 나이·관계·감정 맥락. 발견 기록이 없으면 발견자는 미상이다.
- 상태에는 실제 물건 이동·수량, 부상 이력, 관계 변화와 기억을 남긴다.

## 설정 방법

관리자 → 세계 편집기 → **4. 자원 및 아이템**에서 물건을 만든다. 보관 장소/인물, 접근 구역, 물리적 용도, 휴대 가능 여부, 타격/엄폐 효과를 지정하고 저장한다. 캐릭터의 초기 소지품에도 같은 설정이 있다. 소개에 “돌이 있는 섬”이라고 썼다는 이유만으로 돌이 생성되지는 않는다.

현장 물건은 같은 장소와 구역에서만 사용 가능하다. 여러 개 있는 돌 중 하나를 집으면 바닥 수량이 줄고 새 소지품이 생긴다. 내려놓으면 실제 현재 구역의 바닥으로 돌아온다. 지형지물은 집어 들 수 없다. 일반 물품의 이름만으로 무기 효과를 부여하지 않는다.

나이는 빈칸으로 저장 가능하다. 미설정 나이를 임의로 채우지 않는다. 나이 차이뿐 아니라 친밀/적대 관계·감정을 함께 전달하며, 기본 행동 후보의 대사에도 적용한다.

- 현장 돌 확보와 수량 분리, 소유권, 내려놓기, 부상·관계·기억 저장 확인.

## 남은 한계와 운영 상태

- 전투는 구역 단위 접촉·확률 판정이다. 투척 궤적, 정밀 거리/해부학, 모래 눈공격 등 전용 효과는 구현하지 않았다. 지원하지 않는 물리 결과를 글에서 생성하면 안 된다.
- DAY는 과정이 풍부한 날 4,000–8,000자를 목표로 하되, 사실을 늘려 분량을 강제하지 않는다. 모델에 따라 분량·문체·연결 문장의 품질이 달라지며, 모든 챕터가 정확히 네 배가 된다는 보장은 없다. 자동 검토도 완벽한 문학적/사실적 판정기는 아니다. 주요 결과는 엔진 자료 및 추가 검증으로 제한한다.
- 시도·결과를 기록하므로 부상이 나지 않는 공격도 가능하다. 전투 횟수나 사망자를 강제로 만들지 않는다.
- 운영 세계는 작업 전부터 `PAUSED / WORLD_CONTEXT_TOO_LARGE`였다. 로그에서 최대로 축약한 요청도 20,592바이트였음을 확인했다. 입력의 중복 지시를 줄였으며 5인·전체 규칙·누적 목표 테스트로 요청 한도를 확인했다. 운영 세계를 리셋하거나 유료 틱을 실행하지 않았다. 재개 전까지 이전 오류 표시는 남을 수 있다.
- 기존 DAY 원문은 그대로 둔다. 새 과정 필드는 이후 판정된 행동에 적용되며 과거 사건의 미기록 과정을 꾸며 넣지 않는다.
